Projects

Flagship · now building

Tealbloc

A visual builder for ROS 2 formerly BROS2

Build robot software by connecting blocks. Every block is a real ROS 2 node and every wire is a real topic. Press Run and Tealbloc generates a standard ROS 2 package, builds it with colcon in a managed Docker sandbox, and wires live plots, sliders, a joystick, or your phone into the running graph. Press Deploy and the same graph runs on a Raspberry Pi, Jetson, or ROS 2 robot.

  • 47 blocks
  • 15 guided examples
  • 3 desktop OSes
  • 0 ROS installs needed

Tealbloc · Build & drive

Three blocks, two wires, one click: a real ROS 2 package built with colcon and driven live.

▶ Try it · no install

A tiny Tealbloc, right in your browser

Drag the blocks around, wire an output into an input , and press Run. It's a toy version of the real app, but the ideas are the real ones.

  • Type-checked graphs. Mismatched messages, missing inputs, and conflicting publishers are caught before anything builds.
  • Tune while it runs. Every block setting is a real ROS 2 parameter, so dragging a slider updates the live node.
  • Real hardware. GPIO motors, servos, ultrasonic sensors, gamepads, and Arduino/ESP32 boards, with a simulation fallback.
  • Tested for real. Unit and Playwright suites on macOS, Windows, and Linux, and CI builds and runs every example in real ROS 2.
  • Electron
  • React
  • TypeScript
  • React Flow
  • Python · rclpy
  • Docker
  • ROS 2 Humble & Jazzy
